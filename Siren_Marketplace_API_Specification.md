# Siren Marketplace API Specification

This document provides a detailed specification for the core marketplace API endpoints: **Catches**, **Offers**, and **Orders**.

## 1. Global Configuration

- **Base URL**: `https://api.marketplace.dev.siren.dhi-cm.com/api/v1`
- **Content-Type**: `application/json`

---

## 2. Resources & Endpoints

### 2.1 Catches (`/catches`)

| Method     | Endpoint       | Description                 | Query Params                                |
| :--------- | :------------- | :-------------------------- | :------------------------------------------ |
| **GET**    | `/catches`     | List catches with filtering | `fisher_id` (optional), `status` (optional) |
| **POST**   | `/catches`     | Create a new catch          | -                                           |
| **GET**    | `/catches/:id` | Get single catch details    | -                                           |
| **PUT**    | `/catches/:id` | Update a catch              | -                                           |
| **DELETE** | `/catches/:id` | Delete a catch              | -                                           |

#### Create Request Body

Use the **Catch Model**. The `id` should be generated by the backend if not provided (for POST).

```json
{
  "name": "Tiger Shrimp"
  // ... all required fields (see Detailed Data Models)
}
```

#### Update Request Body

Only specific fields can be updated.

```json
{
  "name": "Tiger Shrimp",
  "initial_weight_grams": 5000,
  "available_weight_grams": 5000,
  "price_per_kg_amount": 2000,
  "total_price_amount": 10000,
  "images": ["url1", "url2"],
  "status": "available",
  "location_name": "Douala Port",
  "latitude": 4.05,
  "longitude": 9.76
}
```

### 2.2 Offers (`/offers`)

| Method     | Endpoint      | Description                     | Query Params                                  |
| :--------- | :------------ | :------------------------------ | :-------------------------------------------- |
| **GET**    | `/offers`     | List offers with filtering      | `catch_id`, `buyer_id`, `fisher_id`, `status` |
| **POST**   | `/offers`     | Submit an offer                 | -                                             |
| **GET**    | `/offers/:id` | Get offer details               | -                                             |
| **PUT**    | `/offers/:id` | Update offer (Status / Counter) | -                                             |
| **DELETE** | `/offers/:id` | Withdraw/Delete offer           | -                                             |

#### Create Request Body

```json
{
  "catch_id": "uuid-catch",
  "fisher_id": "uuid-fisher",
  "buyer_id": "uuid-buyer",
  "current_price_amount": 4500,
  "current_weight_grams": 2000,
  "status": "pending",
  "waiting_for": "fisher" // 'fisher' or 'buyer' depending on who sent it
}
```

#### Update Request Body

**Scenario A: Counter-Offer**
Update price/weight. This automatically sets `status = pending` and toggles `waiting_for`.

```json
{
  "current_price_amount": 4800,
  "current_weight_grams": 2000,
  "waiting_for": "buyer"
}
```

**Scenario B: Status Change**
Accept or Reject an offer.

```json
{
  "status": "accepted" // or 'rejected'
}
```

---

### 2.3 Orders (`/orders`)

| Method     | Endpoint      | Description                | Query Params                                  |
| :--------- | :------------ | :------------------------- | :-------------------------------------------- |
| **GET**    | `/orders`     | List orders with filtering | `buyer_id`, `fisher_id`, `status`, `offer_id` |
| **POST**   | `/orders`     | Create finalized order     | -                                             |
| **GET**    | `/orders/:id` | Get order details          | -                                             |
| **PUT**    | `/orders/:id` | Update order               | -                                             |
| **DELETE** | `/orders/:id` | Cancel/Delete order        | -                                             |

#### Create Request Body

Usually created when an Offer enters `accepted` status.

```json
{
  "offer_id": "uuid-offer",
  "catch_id": "uuid-catch",
  "fisher_id": "uuid-fisher",
  "buyer_id": "uuid-buyer",
  "terms_price": 4500,
  "terms_weight": 2000,
  "status": "active"
}
```

#### Update Request Body

Primarily for status updates.

```json
{
  "status": "completed", // or 'cancelled'
  "cancellation_reason": "Buyer did not show up" // required if cancelled
}
```

## 3. Detailed Data Models

The API **MUST** return JSON objects matching these structures.

### Catch Model (`CatchModel`)

| Field                    | Type         | Required | Description                                                                |
| :----------------------- | :----------- | :------- | :------------------------------------------------------------------------- |
| `id`                     | String       | Yes      | Unique Identifier (UUID)                                                   |
| `name`                   | String       | Yes      | Name of the catch (e.g., "Tiger Shrimp")                                   |
| `date_posted`            | String       | Yes      | ISO8601 Timestamp                                                          |
| `initial_weight_grams`   | Integer      | Yes      | Total weight caught in grams                                               |
| `available_weight_grams` | Integer      | Yes      | weight remaining for sale in grams                                         |
| `price_per_kg_amount`    | Integer      | Yes      | Cost per kg in currency smallest unit                                      |
| `total_price_amount`     | Integer      | Yes      | Total cost in currency smallest unit                                       |
| `size`                   | String       | Yes      | Size classification (e.g., "Large", "00", "L")                             |
| `market`                 | String       | Yes      | Market name/location origin                                                |
| `images`                 | List<String> | Yes      | Array of image URLs                                                        |
| `species`                | Object       | Yes      | `{ "id": "...", "name": "...", "image": "...", "scientific_name": "..." }` |
| `fisher_id`              | String       | Yes      | User ID of the fisher                                                      |
| `status`                 | String       | Yes      | `available`, `soldOut`, `expired`, `removed`                               |
| `observation_id`         | String       | Yes      | Related observation ID                                                     |
| `location_name`          | String       | Yes      | Human readable location                                                    |
| `latitude`               | Double       | Yes      | GPS Latitude                                                               |
| `longitude`              | Double       | Yes      | GPS Longitude                                                              |
| `mesh_size`              | Double       | No       | Mesh size in mm                                                            |
| `gear_length`            | Double       | No       | Gear length in m                                                           |
| `gear_width`             | Double       | No       | Gear width in m                                                            |
| `gear_nature`            | String       | No       | Description of gear nature                                                 |
| `water_depth`            | Double       | No       | Depth in meters                                                            |
| `fishing_time`           | Double       | No       | Duration/Time of fishing                                                   |
| `number_of_shrimps`      | Integer      | No       | Count of individual shrimps if applicable                                  |

### Offer Model (`OfferModel`)

| Field                          | Type    | Required | Description                                  |
| :----------------------------- | :------ | :------- | :------------------------------------------- |
| `id`                           | String  | Yes      | Unique Identifier                            |
| `catch_id`                     | String  | Yes      | ID of the related catch                      |
| `fisher_id`                    | String  | Yes      | ID of the fisher                             |
| `buyer_id`                     | String  | Yes      | ID of the buyer                              |
| `current_price_amount`         | Integer | Yes      | Proposed price (total)                       |
| `current_weight_grams`         | Integer | Yes      | Proposed weight (total)                      |
| `current_price_per_kg_amount`  | Integer | Yes      | Calculated price per kg                      |
| `previous_price_amount`        | Integer | No       | Previous offer price (for history)           |
| `previous_weight_grams`        | Integer | No       | Previous offer weight                        |
| `previous_price_per_kg_amount` | Integer | No       | Previous price per kg                        |
| `status`                       | String  | Yes      | `pending`, `accepted`, `rejected`, `expired` |
| `date_created`                 | String  | Yes      | ISO8601 Timestamp                            |
| `date_updated`                 | String  | Yes      | ISO8601 Timestamp                            |
| `waiting_for`                  | String  | No       | `fisher` or `buyer` (whose turn to act)      |
| `has_update_for_fisher`        | Boolean | Yes      | Unread flag for fisher                       |
| `has_update_for_buyer`         | Boolean | Yes      | Unread flag for buyer                        |

### Order Model (`OrderModel`)

| Field                    | Type    | Required | Description                          |
| :----------------------- | :------ | :------- | :----------------------------------- |
| `id`                     | String  | Yes      | Unique Identifier                    |
| `offer_id`               | String  | Yes      | ID of the accepted offer             |
| `catch_id`               | String  | Yes      | ID of the catch                      |
| `fisher_id`              | String  | Yes      | ID of the fisher                     |
| `buyer_id`               | String  | Yes      | ID of the buyer                      |
| `terms_price`            | Integer | Yes      | Final price agreed upon              |
| `terms_weight`           | Integer | Yes      | Final weight agreed upon             |
| `terms_price_per_kg`     | Integer | Yes      | Final price per kg                   |
| `status`                 | String  | Yes      | `accepted`, `completed`, `cancelled` |
| `date_created`           | String  | Yes      | ISO8601 Timestamp                    |
| `date_updated`           | String  | Yes      | ISO8601 Timestamp                    |
| `has_review_from_fisher` | Boolean | Yes      | If fisher reviewed this order        |
| `has_review_from_buyer`  | Boolean | Yes      | If buyer reviewed this order         |
| `cancellation_reason`    | String  | No       | Reason if status is cancelled        |
